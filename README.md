# DOXA CITY Website

A lightweight premium storefront with:
- Product catalogue
- Product descriptions and Bible verses
- Size/colour selection
- Shopping cart
- Customer name/location
- WhatsApp order generation
- Mobile responsive design
- No payment gateway required

## Before publishing
Open `index.html` and change:
`const WHATSAPP_NUMBER = "233XXXXXXXXX";`

Then replace the product `image` fields with your actual image URLs or local image paths, and edit names/prices/descriptions/sizes/colours.

## Free publishing
This is a static HTML/CSS/JavaScript site. It can be published using GitHub Pages. GitHub Pages supports static files such as HTML, CSS and JavaScript.
